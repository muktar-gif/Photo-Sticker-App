# Photo Sticker App

A React Native mobile application that lets users select photos from their gallery and personalize them with emojis and custom stickers using intuitive gesture controls.

---

## Features

- **Photo Selection** — Pick any image directly from your device's gallery
- **Emoji & Sticker Overlays** — Add emojis and custom stickers on top of your photos
- **Gesture Controls** — Drag, scale, and reposition stickers with touch gestures
- **Save to Device** — Export and save your edited image to your photo library

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS version recommended)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [Expo Go](https://expo.dev/client) app on your iOS or Android device (for physical device testing)

---

## Getting Started

1. **Clone the repository**

```bash
git clone https://github.com/muktar-gif/Photo-Sticker-App.git
cd Photo-Sticker-App
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the development server**

```bash
npm start
```

4. **Run on your preferred platform**

```bash
# Android
npm run android

# iOS
npm run ios

# Web
npm run web
```

Scan the QR code shown in the terminal with the Expo Go app on your device to launch the app.

---

## How to Use

1. Open the app and tap the button to select an image from your gallery.
2. Choose an emoji or custom sticker from the sticker picker.
3. Use touch gestures to drag, resize, and position stickers anywhere on your photo.
4. When you're happy with the result, tap **Save** to export the image to your device.
